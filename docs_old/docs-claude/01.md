## File `.npz` được sinh ở đâu?

**Tất cả file `.npz` được sinh lazy trong `load_data.py`** tại hàm `get_norm_adj_mat()` ([load_data.py:388](hr/utility/load_data.py:388)):

| File `.npz` | Được tạo bởi method |
|---|---|
| `s_interaction_adj_mat.npz` | `create_interaction_adj_mat()` |
| `s_social_adj_mat.npz` | `create_social_adj_mat()` |
| `s_similar_users_adj_mat.npz` | `create_similar_adj_mat()` |
| `s_tfidf_item_similarity_adj_mat.npz` | `create_tfidf_similarity_matrix()` |
| `s_bert_item_similarity_adj_mat.npz` | `create_bert_similarity_matrix()` |
| `s_full_bert_item_similarity_adj_mat.npz` | `create_full_bert_similarity_matrix()` |
| `s_img_similarity_adj_mat.npz` | `create_img_similarity_matrix()` |
| `s_multimodal_similarity_adj_mat.npz` | `create_multimodal_similarity_matrix()` |

**Cơ chế hoạt động** ([load_data.py:388](hr/utility/load_data.py:388)): mỗi `try/except` block kiểm tra file `.npz` có tồn tại chưa — nếu có thì load lên, nếu không thì tính toán rồi `sp.save_npz(...)` lưu xuống. Tức là **lần đầu chạy model thì mới sinh**, sau đó cache lại.

**Tóm lại luồng 2 giai đoạn:**
1. **Notebook** → xử lý raw data VCR → sinh `train.txt`, `test.txt`, `items_features.csv`, ...
2. **`load_data.py` khi chạy model lần đầu** → đọc các file trên → tính toán → lưu các `s_*.npz`
