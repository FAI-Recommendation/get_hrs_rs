### 1. Thuật Toán Tensor Ma Trận Đo Chuẩn Tương Đồng (Cosine Similarity)
Hàm `create_img_similarity_matrix(self, ...)` tái thiết lập định dạng Vector trong DataFrame để đo giao cấp:

```python
def create_img_similarity_matrix(self, threshold=0.5):
    # Trích xuất toàn bộ dữ liệu cột mảng 'feature3' (Matrix cấu trúc 1280 ảnh) lên System Ram hệ Numpy vstack (Float 32 bit)
    image_embeddings = np.vstack(
        self.items_features['feature3'].apply(parse_vector_string).values
    ).astype(np.float32)
    
    # Ứng dụng Sklearn Cosine đo đạc khoảng cách góc hệ chuẩn tạo độ Similarity chéo tương duyên đa cấp.
    similarity_matrix = cosine_similarity(image_embeddings, image_embeddings)
    
    # Lọc Cắt Ngưỡng Nhiễu: Đặt Threshold (Ngưỡng 50%), xoá tính liên kết mành (Cắt Node yếu hơn 0.5 về 0)
    similarity_matrix[similarity_matrix < threshold] = 0
    
    # Nén Trị Cấu Trúc Sparse Model theo csr_matrix nhằm loại bỏ lượng lớn Memory hao tốn ở trạng thái ma trận bằng số 0.
    return sp.csr_matrix(similarity_matrix)
```

### 2. Bộ Nhớ Cache Lọc Giảm Chi Phí Sinh Lưu Ma Trận File
Bởi vì hàm toán học Vector Dimensionality rất lớn và lặp chu kỳ nặng VRAM. Tiến trình tích hợp Luồng Caching thông qua Try-Catch ngoại lệ vào thẳng Function lấy Matrix `get_norm_adj_mat()`:

```python
        try:
            # Truy xuất cấu trúc Đồ Mạng Đệm - Loading Cache Memory System vào Model
            img_similarity_adj_mat_sym = sp.load_npz(self.path + '/s_img_similarity_adj_mat.npz')
        except Exception:
            # FALLBACK KHỞI TẠO CACHE MỚI (CHẠY LẦN ĐẦU)
            # Truy xuất gọi ngầm hàm Tính Toán Graph Graph Matrix Topology từ Code 1
            img_similarity_adj_mat = self.create_img_similarity_matrix(threshold=0.5)
            # Hàm Normalization chuẩn hoá kích thước Tensor Weight
            img_similarity_adj_mat_sym = normalized_sym(img_similarity_adj_mat)
            
            print('Đang xử lý tạo dữ liệu ma trận ảnh & Chuyển nén phân bổ IO file .npz mới...')
            # Push File ra vùng Local Directory lưu trữ Server:
            sp.save_npz(self.path + '/s_img_similarity_adj_mat.npz', img_similarity_adj_mat_sym)
```

**Tổng quan nguyên lí Logic Cache:** Trong thời điểm Build môi trường Cold-run lần đầu tiên, Application sẽ gồng tính toán xử lý tệp `.csv` trong một thời gian ngắn hòng cấu tạo ra ma trận `s_img_similarity_adj_mat.npz` lưu ở hệ FileSystem nội tuyến. Kể từ chu trình kiểm thử/huấn luyện (Re-training) lần 2, GCN Engine Core sẽ hit thẳng vào Cache System `.npz`. Qua đó tiến trình sẽ nhảy vọt bỏ qua vòng lặp xử lý logic Toán Cosine làm cho Mạng Học Trí Tuệ Graph Convolution Network tải nạp Input vô cùng thanh thoát.
