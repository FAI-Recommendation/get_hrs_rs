# Cơ Chế Đọc Dữ Liệu Hình Ảnh Trong Mô Hình GCN

Khi phân tích cấu trúc của các thư mục tiền xử lý hình ảnh (ví dụ: `Data/vcr1p_img_m1_img`), một điểm đáng lưu ý là **hệ thống không hề lưu trữ bất kỳ tệp dữ liệu ảnh gốc nào (.jpg, .png)**. Dù tham số môi trường có tên module tải đặc trưng Hình ảnh, nhưng thực tiễn hệ thống lại không yêu cầu việc nạp và xử lý trực diện với mã hệ ảnh Pixel.

Đây là cơ chế làm việc cơ bản đối với các lĩnh vực Đồ Thị Tensor Phức (Graph Convolutional Networks - GCN) có quy mô lớn:

---

## Bước 1: Giai Đoạn Tiền Xử Lý Ngoại Tuyến (Offline Preprocessing Image Embeddings)

Cấu trúc đồ thị Machine Learning không thể và không nên phân rã dữ liệu phân mảng Pixel một cách Real-time theo số lượng lên đến hàng triệu Model. Trước khi tiến trình huấn luyện được chạy tự động, cấu trúc hình ảnh đã được giải nén và chuyển hóa ở phân cấp Model Computer Vision:
1.  Toàn bộ cụm ảnh `.jpg` của dự án phải chạy xử lý chắt lọc qua các tầng Neuron trích xuất ảnh nhận dạng (ví dụ Kiến trúc MobileNetV2 / ResNet).
2.  Pipeline lược đi phần tính dung lượng và lưu trữ lại **Vector Số Học (Embeddings Vector)** với chiều rộng ma trận khoảng 1280 biến cho mỗi mặt phẳng áo nhằm biểu diễn tính kết cấu, màu sắc, hoa văn.
3.  Sau quy trình trích rã, Model thực hiện bài toán Cường độ tương quan chéo **Similarity Calculation (VD: Thuật toán Cosine)** để lập thành các node nối liên đới của Đồ Thị (Ví dụ Áo A đạt >= 80% tính tương đồng Vật Thể Áo B, thì chúng sẽ được vẽ một đường nối - "Cạnh" Graph).

## Bước 2: Nén Vector Ma Trận Kề (Matrix Compression NPZ Loading Phase)

Cấu trúc mạng lưới liên kết của Mảng hình Crossover Image Similarity sẽ được tối ưu trên toàn tuyến kiến trúc chuyển đổi dữ liệu, hệ thống xuất Output các ma trận Mạng Khảo Sát Tương Đồng **Ma Trận Kề (Adjacency Matrix)** lưu dưới chuẩn format Python định danh ma trận là file `.npz`.

Đứng dưới góc nhìn dữ liệu (Data Folder) lúc Code GCN hoạt động nạp File, những mã nén `.npz` dưới đây tương quan trực tiếp từ đặc trưng ảnh và câu chữ NLP:
*   📄 **`s_img_similarity_adj_mat.npz`**: Đại diện đồ thị hình thể hình thức hóa theo **chỉ số Hình Ảnh (only_img matrix topology)**.
*   📄 **`s_bert_item_similarity_adj_mat.npz`**: Đại diện đồ thị mối tương đồng vật lý **Văn bản mô tả - Text BERT (NLP matrix topology)**.
*   📄 **`s_multimodal_similarity_adj_mat.npz`**: Định dạng File quy định mạng **Hybrid Lai Tạp Đa Hình (BERT text + CNN image)** nạp ở code đồ thị phân cấp `bert_img`.

## Nguyên Lý Thực Chức Và Ứng Dụng:

*   **Bảo vệ giới hạn phần cứng (Speed Execution):** Cấu trúc Data nếu GCN phải tải vòng tải lập ảnh Array `vạn file .jpg/ epoch`, kiến trúc Disk I/O Bottleneck và Tắc Nghẽn Vram/Ram sẽ gây Crash toàn Server ngay sau 3 phút chạy.
*   **Module Ràng Buộc Phân Rã (Decoupled Micro-Features):** Tiến trình AI (Đo hình nhận vật) là hệ thống DeepLearning riêng rẽ tách biệt so với Hệ Xương Sống Toán GCN (Truyền tải Graph Model User Interaction). 

**Tổng kết:** Tại mã file chạy Model Graph hàm `get_norm_adj_mat()`, Model sẽ truy cập `s_img_similarity_adj_mat.npz` vào kiến trúc hệ Đồ thị Lưới nhằm nội suy đặc tính Hình Học Vật Lý của Data Input thông qua khái niệm hệ số góc Toán Học không gian Vector hoá (Embeddings Matrix) mà không truy quét trực quan Ảnh con người.
