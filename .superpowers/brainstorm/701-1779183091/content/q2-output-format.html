Output format của evaluate script?

Ảnh hưởng đến cách tổ chức code và cách dùng sau này

A

Jupyter Notebook (.ipynb)

Chạy từng cell, xem chart trực tiếp trong notebook.
Dễ chỉnh sửa, thêm markdown giải thích từng biểu đồ.
→ Phù hợp để làm báo cáo / trình bày chuyên đề.

⭐ Recommended — dễ trình bày, cell by cell
B

Python Script (.py)

Chạy 1 lần, export tất cả charts ra thư mục.
Dễ tích hợp vào pipeline, chạy lại khi có data mới.
→ Phù hợp để tự động hóa sau mỗi lần thêm run mới.

C

Cả hai — Script + Notebook

Script: load_data.py — đọc tất cả summary.json → dict
Notebook: evaluate.ipynb — import dict, vẽ charts
→ Tách biệt data loading và visualization, dễ maintain.
